## 🌟 Основні фішки для дитини:

1. **🧭 Інтерактивна Карта Скарбів**:
   - Кожне завдання — це зупинка в експедиції (*«Бухта Блискучих Зубок»*, *«Острів Порядку в Кімнаті»*, *«Печера Книжкових Загадок»*, *«Щит від Екранних Монстрів»* тощо).

2. **🐶 Вірний друг Бруно**:
   - Анімований песик у капелюсі мандрівника.
   - Можна натиснути на Бруно або кнопку **«Погладити»** — він виляє хвостиком, грайливо гавкає та підбадьорює кумедними фразами.

   - Дитина накопичує зароблені дублони та обмінює їх на реальні призи від батьків (*«Вибір мультфільму на вечір»*, *«Капітанське морозиво»*, *«Похід у парк розваг»*, *«Нова настільна гра/книга»*).

4. **🏖️ Щоденний Скарб (Міні-гра)**:
   - Раз на день дитина може обрати таємну ділянку на піщаному пляжі й розкопати бонусні монети лопаткою.
